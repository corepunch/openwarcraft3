Warcraft III glue panel animations
==================================

Panel and tab groupings (from glue_panels[] in menu_glue_scene.c)
------------------------------------------------------------------
UI_GotoGluePanel receives one GLUEDEST {panel, tab}. Full panel transitions
play the panel's Birth/Death family on both layers. At idle, the right layer
holds the base Stand and the left uses its explicit tab definition.

Panel                           Tab  Enter                      Rest                         Leave
MainMenu                          0  MainMenu Birth             MainMenu Stand               MainMenu Death
RealmSelection                    0  RealmSelection Birth       RealmSelection Stand         RealmSelection Death
SinglePlayer                      0  SinglePlayer Birth         SinglePlayer Stand           SinglePlayer Death
SinglePlayer                      1  SinglePlayerSkirmish Morph SinglePlayerSkirmish Stand   SinglePlayerSkirmish Morph Alternate
Options                           0  Options Birth              Options Stand                Options Death
Options                           1  Options Morph              Options Stand Alternate      Options Morph Alternate
MultiplayerPreGameChat             0  MultiplayerPreGameChat Birth / Stand / Death
MultiplayerPreGameChat             1  MultiplayerSubmenu Morph   same Morph held at @1.0000   MultiplayerSubmenu Morph Alternate
BattlenetCustom                    0  BattlenetCustom Birth      BattlenetCustom Stand        BattlenetCustom Death
BattlenetCustom                    1  BattlenetCustomCreate Birth BattlenetCustomCreate Stand BattlenetCustomCreate Death
BattlenetCustom                    2  BattlenetAdvancedOptions Morph / same Morph held at @1.0000 / Morph Alternate

Enter/Leave for nonzero tabs describe tab-only changes, with right chrome at Stand.
Create has no Morph sequence. Submenu and AdvancedOptions have no Stand sequence.
These are explicit authored families, not names generated from a shared suffix rule.
Repeated/reversed requests finish the running morph before honoring the latest tab.
Two non-default tabs transition through tab zero.

All four models expose the same 62 sequence names, indices, intervals, and flags.
Intervals and durations are milliseconds. Flag 0x1 marks an authored non-looping sequence.
